## P0-1 分割前景 id

根因：MuJoCo 4.0 分割返回 `(objid, objtype)`，geom 的 objid 是 0 基 geom id，背景为 -1；旧代码把 geom id `+1` 后直接 `isin`，等于整体错位到下一个 geom，`geom=0` 的地面还会被当成前景。

修改：`vlab/rendering/hybrid.py`
- `foreground_ids(env)` 直接返回真实 geom id（不再 +1）。
- 新增 `segmentation_mask(seg, ids)`：`np.isin(seg[:,:,0], ids) & (seg[:,:,1] == mjOBJ_GEOM)`，排除背景和非 geom 实体。
- `compose` 统一走该掩码。

回归：`tests/test_segmentation.py`（最小复现 + 真实机器人场景）。证据：`outputs/phase2-render-validation/third-round/masks/`（`minimal_floor0_cup1.png`、`real_front_mask.png`、`real_front_classes.png`、`segmentation_evidence.json`）。
- 最小场景：cup 400 px、pad 178 px；新掩码 578 px；旧 `+1` 掩码 178 px 且杯子 0 px。
- 真实 front：FG 28 个 geom，掩码 6592 px；杯 id 7–18 = 860 px；左/右指垫 144/179 px；托盘 1522 px；连杆 geom 15 个；掩码内 objtype 全为 GEOM；世界地面/桌面 0 个。

## P0-2 splat 协方差与深度

根因：EWA 投影把世界系协方差直接送入雅可比，忽略相机旋转；深度用射线欧氏距离，与解析盒的相机 Z 深度不可比；最近深度无条件写整幅图。

修改：`vlab/splat_render.py`
- 先 `Sigma_cam = Rcᵀ Σ_world Rc`（`Rc` 为相机到世界旋转，列为相机轴），再 `Σ_2d = J Σ_cam Jᵀ + 0.3 I`。
- `ray_box_hit` 返回相机系 Z 深度（`tmin / n_z`，且要求 `tmin > 0`）。
- 深度图仅当 splat 有效 alpha 时取最小；透明高斯继续按 alpha 混合，不当作不透明表面。

回归：`tests/test_covariance_camera.py`
- roll 0°：足迹 97×11 px，主轴角 0°；roll 90°：13×89 px，主轴 90°。
- pitch 12°、yaw 12° 投影在视场内且方向正确。
- 20 万样本经验协方差 vs 解析投影（小高斯，避免透视非线性）一致。
- 离中心主点 (128,128)；`fx≠fy`、实例旋转/缩放均覆盖。
- 盒前缘相机 Z 1.95 m，欧氏距离 1.981 m；有效深度像素数 == 覆盖像素数（1209）。

## P0-3 hybrid 构建与缓存一致性

根因：`engine._build` 引用了不存在的 `config`，自定义碰撞代理场景直接 NameError；缓存键只含部分参数；预览/帧/采集可能走不同渲染路径。

修改：
- `vlab/engine.py::_build` 使用 `cfg`，默认桌面关闭时校验至少一个启用碰撞代理。
- `vlab/rendering/hybrid.py`：进程级有界 LRU（≤4），键 = ply SHA256 + 渲染器版本 + 模式 + 相机位姿/内参/分辨率 + 场景实例；只读背景/深度；`clear_background_cache`。
- `render()`、`frame.jpg`、Gym `observation()` 统一调用 `_render_camera`；非 front 相机明确抛 `UnsupportedMode`。

回归：`tests/test_hybrid_cache.py`——显式碰撞代理可构建；缺失/全禁用代理拒绝；内参/分辨率/实例变化键变化；缓存上限 4；相机位姿/焦距/分辨率变化触发重建；预览与 `_render_camera` 完全一致、与纯 MuJoCo 差异 >5%。

## P0-4 场景保存原子性

根因：实例与碰撞代理分两次请求写、且用 `model_copy(update=...)` 绕过字段/跨字段校验，失败时可能留下半更新配置。

修改：`vlab/api.py`
- 新增 `PUT /api/v1/projects/{pid}/scene`，请求含 `environment`、`colliders`、`use_default_table`、`work_surface_z`、`expected_version`。
- 服务端在锁内：完整 `ProjectConfig.model_validate` + `validate_config`（含物理构建）→ 全成功才单次落盘并升版本。
- 任何失败版本不变；`expected_version` 过期返回 409 且附 `current_version`；旧 `instance`/`colliders` 端点内部走同一提交函数。
- 前端“保存全部”只发一个请求。

回归：`tests/test_scene_commit.py`——8 类非法输入（负缩放、零四元数、位置维度错、重名、摩擦非法、圆柱非等径、未知资产、缺字段）全部 400 且当前版本不变；陈旧版本 409 且返回当前版本；旧拆分端点同样拒绝。

## P0-5 画布世界变换

根因：gizmo 绑在子 mesh 上而实例变换在父组，平移被重复应用；四元数未生效；圆柱几何轴为 Y，场景为 Z-up。

修改：`frontend/src/components/SceneCanvas.tsx`
- 实例组承载 position/quaternion/scale，子 mesh 只保留局部几何。
- 碰撞代理组承载位姿；圆柱几何预旋转 X 90° 使轴对齐 Z。
- `TransformControls` 绑定完整变换对象，提交时读组的位置+四元数；平移/旋转模式切换。
- 提供 `window.__sceneDebug` 与 `frontend/scene-debug.html` 浏览器测具。

验证（内置 Chromium WebGL2，`frontend/scene-debug.html`；数值证据 `outputs/phase2-render-validation/third-round/editor_transform.json`）：
- 实例起始 [1,2,3]，世界 X +0.2 → [1.2,2,3]（无重复平移）。
- 150° 旋转四元数 `[0,0,0.9659,0.2588]` 提交到 `__lastInstance`，回读一致。
- 圆柱 child bbox `[0.2,0.2,0.5]`（轴向 Z），组平移 [0.5,0.1,0.25] 提交到 `__lastCollider`。
- 真实页面：保存 [0.5,0.6,0.7]/90° → 后端 v4；刷新显示已保存值；撤销/重做代理数 1→2→1→2；版本冲突由原子提交 409 覆盖。
- 限制：自动化未模拟鼠标按住 gizmo 拖动，而是走同一提交路径注入非零初值；内置浏览器截图为 0×0 隐藏视口，无法产出画布截图，结构/数值证据已保存。高斯资产只提供全景预览，不称为“高斯三维编辑器”。

## 受限渲染模式（明确声明）

- 模式名：`static_background_overlay`；渲染器版本：`hybrid:3`。
- 语义：世界固定前视相机 → splat 背景渲染一次（进程缓存）+ MuJoCo 全前景（机器人+任务物+托盘）叠加；**splat 不遮挡机器人**，因此不是完整遮挡合成，也不是数字孪生/sim2real。
- 写入：数据集 `manifest.json`（`render_mode/sensor_renderer/renderer_version/gaussian_sha256`）、训练 checkpoint 与报告 `render_meta`、评估报告逐回合 `render_mode`。
- 拒绝：腕部相机或运动相机在 hybrid 模式明确报错；场景无桌面/碰撞代理时拒绝构建。
