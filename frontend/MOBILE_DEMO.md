# 四轮移动机器人 Demo

入口：**http://127.0.0.1:5173/drive**。传送带首页和场景工作台均提供移动入口；前后端启动方式见 [DEMO.md](DEMO.md)。

需要把驾驶与抓取连起来时，打开 **http://127.0.0.1:5173/transport** [VLA 仿真工作台](VLA_WORKBENCH.md)：支持传送带抓取入箱、拿起原位放回、入箱后再取出保持，以及入箱后取出沿原路返回并放回传送带。可地图选择场区内箱位、更换物品、自定义箱体、使用参数建议与双相机采集。任务执行后按真实接触、支撑和稳定性判断各子任务结果。

`/transport` 侧边导航分为工作空间、任务要求、模型资产、执行策略、仿真执行、可行性结果、数据集和参数设置八个独立模块。VLA 页显示真实服务连接和权重身份；状态专家与模型策略分别标记。公开 SmolVLA 的当前适配只控制机械臂 XYZ 与夹爪，完整移动 VLA 需要带移动动作的策略；本页的手动驾驶功能不依赖 VLA 服务。安装、启动及适配边界见 [VLA_WORKBENCH.md](VLA_WORKBENCH.md)。

## 操作流程

1. 选择已有的 Aholo 底盘外观，点击“启动移动仿真”。本版复用已导入模型，不创建新收费生成任务。
2. 按住网页方向按钮，或使用 `WASD`／方向键控制前进、后退、左右转。可组合前进与转向，滑块设置目标速度。
3. 松开按键、按空格／Esc 或点击“停车”可减速停车。切换窗口、隐藏页面或离开页面也会请求停车；后端手动控制超过 450 ms 没有新指令会归零目标速度，示例路线超过 1.5 秒未收到网页状态查询也会中止并停车。
4. 切换场地前视和车载相机，查看真实位置、速度、航向、累计路程和轨迹。相机来自后端 MuJoCo 渲染。
5. “运行示例路线”执行固定的四航点路线并停车。这是位置反馈控制演示，尚无自主规划或避障；手动驾驶或停车可以中断路线。
6. “开始记录数据”后驾驶，随后“结束记录并保存”，下载 JSON 清单和 NPZ 数据。也可“结束会话并保存记录”。记录过程中先结束记录才能复位。

刷新会恢复当前会话，但先停车。后端重启后，旧物理会话结束，需要重新启动；已有数据保留。无人查看 90 秒或会话满 10 分钟时自动结束并保存记录。

## 机构与物理

复用真实 Aholo 资产 `imported/four-wheel-robot-chassis-82e8e5`（任务 `8337214`）以及原有关节机械臂。原始生成网格保持不变，作为完整外观壳体；四个可见独立驱动轮另行装配，轮径、轴距、质量和摩擦采用演示估计。生成模型本身不包含可执行轮轴。

底盘是 MuJoCo 六自由度刚体，四个铰接轮由速度执行器驱动，通过轮地摩擦产生运动。转向采用左右轮差速与轮胎侧滑，不给底盘直接写运行期位置或速度，也没有平面位移伺服或焊接约束。地面、场地围栏和箱体有真实碰撞。

最大目标线速度 0.22 m/s、角速度 1.8 rad/s；目标变化经过加速度限制，真实速度受惯性、摩擦和接触影响。`/drive` 中机械臂保持关节位置，随底盘移动，本页只执行驾驶与记录；真实移动抓取及顺序搬运在 `/transport` 执行。[旧场景工作台](SCENARIO_WORKBENCH.md) 的抓取任务仍采用停靠底盘。外观资产不会自动变成任意可执行机器人机构。

## 数据

驾驶数据保存在 `datasets/mobile/mobile_<id>/`，记录频率 20 Hz：

| 字段 | 内容 |
| --- | --- |
| `time` | 动作前仿真时间，单位秒 |
| `base_pose` | 世界坐标位置和 `qw,qx,qy,qz` 四元数 |
| `base_velocity` | MuJoCo 自由关节速度，顺序 `vx,vy,vz,wx,wy,wz` |
| `wheel_qpos`、`wheel_qvel` | 前左、后左、前右、后右轮的角度和转速 |
| `arm_qpos` | 当前机械臂关节位置 |
| `command` | 随后 50 ms 施加的、经过加速度限制的线／角速度目标 |
| `requested_command` | 加速度限制前的用户或路线指令 |
| `control_mode` | 手动 `manual` 或示例路线 `route` |

每帧以动作前状态 `S_t` 配对随后实际施加的 `A_t`。清单包含资产来源／哈希、物理近似、采集时间和字段说明。**驾驶数据当前只包含运动状态和指令，实时相机图像不写入 NPZ**，清单明确记录 `images_recorded=false`。

这些2维线／角速度驾驶指令与 `/transport` 的 `mobile7_v1` 7维动作属于不同契约。后者记录机械臂 XYZ／夹爪、底盘线／角速度与保持手臂标志，并保存双相机及顺序任务完成事件。训练或合并数据前应读取各自清单，不能将驾驶 NPZ 当作已有图像的 VLA 训练样本。

记录期间逐帧写入 JSONL，结束后生成 NPZ 和清单；进程异常重启后可从已落盘完整帧收尾并标记为 `interrupted`。空记录导出时也保持一致的数组维度。

## 接口与验证

接口统一使用 `/api/v1/mobile/`：`GET capabilities`、`POST sessions`、`GET sessions/{id}`、`POST sessions/{id}/command`、`stop`、`route`、`reset`、`record`、`DELETE sessions/{id}`；下载为 `datasets/{id}/manifest` 和 `datasets/{id}/data.npz`。

物理与渲染在同一个会话线程执行，请求读取缓存。提交 ID 保证重复启动请求返回同一会话；指令序号阻止旧心跳在停车后重新启动运动。复位递增 epoch，使网页拒绝复位前迟到画面。

检查命令：`python -m pytest tests/test_mobile_physics.py tests/test_mobile_api.py -q`，前端 `npm run build`。
