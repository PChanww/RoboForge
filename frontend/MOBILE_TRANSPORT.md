# 传送带抓取、移动搬运与自定义入箱

入口：**http://127.0.0.1:5173/transport**。同一 MuJoCo 场景中执行不停带跟随抓取、接触夹持、四轮移动、箱内受控释放，保存状态、动作和双相机数据。启动方式见 [DEMO.md](DEMO.md)。

## 操作

1. 描述任务，例如：“从不停运行的传送带上抓取物品，移动到箱子坐标(0.75,0.65)，放入箱内，采集1条。”文字解析识别已支持的参数，地图和控件也可直接设置。
2. 点击地图放箱，或输入世界 X、Y（米）。检查方案后显示路线，运行时叠加真实轨迹。恢复后方位置可沿用原直线后退布局。
3. 选择已有 Aholo 物品，或描述新物品并选择生成。可手填高、宽、深、质量、摩擦；自动补全保留用户明确填写的值。
4. 设置动作倍率（1～2倍，默认1.6倍）。调整开口箱宽、深、墙高和颜色，也可描述并生成 Aholo 箱子外观，或复用已有外观。
5. 检查执行方案：查看可达性、有效参数和本次生成数量，此操作不提交模型生成。
6. 点击开始，按方案生成／复用资产。新模型会使用后端配置的 Aholo 额度，生成后暂停等待用户预览并选择保存／仅本次使用／放弃；全部确认后再仿真采集，页面显示真实生成阶段进度。
7. 查看双相机、夹握、实际位置、已行驶距离和目标距离。下载清单、配置和 NPZ。失败按实际结果保存，停止本轮后续示范。

修改控件会清除任务文字中对应的旧数字，避免旧要求覆盖新设置。默认 Aholo 物品为 `imported/yellow-plastic-duck-a08e3e`，底盘为 `imported/four-wheel-robot-chassis-82e8e5`。切换已有物品保留原外形；描述新外形需要选择生成模式。

## 执行范围

| 项目 | 本版行为 |
| --- | --- |
| 场景 | 单传送带、单物体、单机器人、一个目标箱，全程不停带 |
| 目标位置 | 世界 X 为 -1.2～1.2 m、Y 为 -0.6～1.5 m，箱体外轮廓须完整在场区内 |
| 路径 | 绕开已知传送带和目标箱，选取可到达停靠点；越界、重叠或不能停靠时拒绝执行 |
| 旧布局 | 未指定坐标时后退30～55 cm并放入后方箱 |
| 抓取 | 随机或固定初始姿态、跟随下降、双侧夹紧、抬升确认 |
| 物品参数 | 高2～7.5 cm，宽深1.5～8.5 cm，质量5～150 g，滑动摩擦系数0.2～3 |
| 箱体 | 宽深16～30 cm、墙高4～9 cm；第三项是墙高，箱底面高约0.9 cm |
| 速度 | 动作倍率1～2；带速独立设置为1～3 cm/s |
| 采集 | 每轮1～5条，每条重置一物体并递增种子，最多90仿真秒 |

这是有限平面场区内对已知静态障碍的路径规划，不包含动态障碍感知、跨房间导航或任意机器人结构生成。环境、机械臂和轮组沿用演示模板，尚不支持连续多物体来料。新外形、参数组合和种子仍可能抓取失败。

## 参数与模型来源

用户填写数值和描述中带明确单位的参数优先。来源逐字段区分 `user_explicit`（用户指定）、`model_inferred`（语言模型建议）、`rules_estimate`（本地规则估计）。已有物品未覆盖的参数沿用资产配置。

Aholo 生成外观网格，不提供质量或摩擦测量。参数建议可使用后端已有的 `AUX_MODEL` 语言模型配置；未配置、调用失败或返回无效值时明确展示规则推荐及原因。生成新物品前也会补全缺省项并记录来源。所有物性数值未经实物标定。

本轮本机未配置参数建议语言模型，默认使用规则推荐；它与 Aholo 网格生成是两套独立能力。源模型不改动，运行配置对物品做 XYZ 缩放并设置质量、摩擦。原资产过大或不满足任务物性要求时会拒绝复用。

箱底和四块独立薄壁参与真实开口碰撞。生成／复用箱网格仅负责外观并缩放至指定外轮廓，不保证精确开口拓扑；视觉网格与物理代理可能有差异。代理与外观来源均写入配置。

## 物理与控制

物品和底盘为独立自由刚体，轮地接触驱动底盘，双侧夹爪接触保持物品。运行期不写入物品或底盘位姿，没有抓取焊接约束。Aholo 物品用网格凸包碰撞，生成底盘提供外观，机械臂及四个驱动轮由 RoboForge 组装。

确认夹握并抬离带面后收拢手臂，再沿路线前进或倒车。线速度和角速度均限加速度。到位后保持夹持，真实轮地转向朝向箱体并稳定停车，再按底盘位姿求解机械臂逆运动学，越箱沿、下降、松爪、撤离和检查稳定；避免左后方放置时关节目标跨越±π造成整圈跳变。相对夹爪下滑超过3 mm时，每50 ms最多收紧0.5 mm，保留闭合下限与9 N／侧力限；持续失去双侧接触会记录失败。

估计参数：底盘主体6 kg，轮半径28 mm、轴距200 mm、轮距156 mm；直行速度基值0.065 m/s、加速度基值0.12 m/s²，再乘倍率并限幅。坐标导航模式轮／地滑动摩擦为0.15，转向轮速需求使用4倍补偿以适应固定轮轴的侧滑转向，未经实物标定，来源写入配置。物理步长2 ms，控制与记录间隔50 ms。

成功需曾夹握和抬升、实际抵达停靠点（坐标模式误差小于6 cm，旧模式达到后退目标减3 cm）、受控释放、物品水平边界在箱内、接触箱底、无夹爪接触且低速稳定至少6个周期。目标、规划路线和真实轨迹分别保存。专家读取仿真状态，尚非仅依靠图像执行的学习策略。

## 数据与恢复

数据位于 `datasets/transport/transport_<id>/`：`run.json`、`manifest.json`、`config.json` 和 `episodes/epNNN.npz`。

| NPZ字段 | 内容 |
| --- | --- |
| `time` | 动作前仿真时间 |
| `base_pose`、`base_velocity` | 世界位置、qw/qx/qy/qz与自由关节6维速度 |
| `wheel_qpos`、`wheel_qvel` | 前左、后左、前右、后右轮角度和转速 |
| `arm_qpos` | 手臂与夹爪7关节位置 |
| `object_pose`、`object_velocity` | 物品位姿与速度 |
| `belt_speed_m_s`、`phase`、`contacts` | 带速、阶段与双侧接触数 |
| `action` | 7维：手臂4维、限幅后线速度、角速度、保持手臂标志 |
| `requested_action` | 限幅前的专家请求 |
| `image_front`、`image_wrist` | 同时刻真实前视480×360、腕部256×256 RGB |

每帧保存动作前 S_t 与随后50 ms应用的 A_t，两相机零模拟延迟。JPEG解码为 uint8 RGB，不缩放裁切。清单保存参数及来源、网格及哈希、代理、路线、配置文件字节SHA-256、相机校准、运行库版本及实际结果。动作是控制指令，真实关节和底盘响应保存在状态里。

网页保存草稿、请求ID和实验ID，刷新恢复同一任务。后台独立推进，相同请求ID返回原任务，同一时间执行一条组合实验。停止先保存已有完整帧。

生成时停止会阻止后续资产提交，已提交远端任务保留；可恢复已知任务下载与导入，未知提交不会盲目重复收费。重启将未完成任务标记 interrupted，不自动重复仿真。异常退出可能丢失当前 Episode 尚在内存的帧。

## 接口与验证

统一前缀 `/api/v1/transport/`：

| 操作 | 接口 |
| --- | --- |
| 能力和资产 | GET capabilities |
| 参数补全 | POST suggest-object：description、可选 current_parameters |
| 检查方案 | POST plan |
| 启动 | POST runs：spec、client_request_id |
| 状态和画面 | GET runs/{id} |
| 停止／恢复生成 | POST runs/{id}/stop、POST runs/{id}/retry |
| 下载 | GET datasets/{id}/manifest、/config、/episodes/{index} |
