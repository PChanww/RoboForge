# RoboForge Studio

旧版文字任务工作台的入口是 `http://127.0.0.1:5173/studio`。根路径现在展示[塑料鸭传送带分拣](DUCK_SORTING.md)，`/collect` 保留 Aholo 杯子的[简单演示](DEMO.md)，原有平台保留在 `/projects` 等路径。用户已授权鸭子任务所需的后端扩展，原有抓杯与 Studio 任务保留。

## 使用流程

1. 输入场景、操作对象、目标和采集数量，点击“生成任务方案”；也可以选择一个示例。
2. 检查方案中的场景、操作类型、物体、颜色、目标位置、数量和随机种子。修改后，右侧更新实际仿真场景预览。
3. 点击“执行任务并采集”。执行期间切换前视、腕部相机，观察实际阶段、接触反馈、末端位置和夹爪开度。
4. 完成后进入“数据与回放”，选择 Episode，播放或拖动时间轴。画面、末端高度、夹爪曲线和四维动作来自该条 NPZ 中同一条记录。
5. 下载 JSON 清单或当前 Episode 的 NPZ；也可以在左侧“最近实验”中重新打开历史结果。

可以直接输入：

```text
在分拣工作台上，把红色方块搬运到右侧托盘，随机摆位，采集3条示范。
```

```text
在简洁工作台上，把绿色方块沿桌面推到中间目标区，采集两条示范。
```

```text
在实验台上，把蓝色圆柱放到左侧托盘，固定摆位，采集1条示范，种子42。
```

## 当前能力

| 项目 | 支持范围 |
| --- | --- |
| 需求解析 | 后端本地规则解析，明确标记为“本地任务解析”，无外部模型调用 |
| 场景 | 简洁工作台、分拣工作台、实验工作台；桌面颜色和静态道具参与实际场景构建 |
| 物体 | 方块、圆柱、标准杯、高杯、宽口杯；提供五种颜色 |
| 操作 | 抓取与放置；方块沿桌面直线推移 |
| 目标 | 左侧、中央、右侧；推移任务的目标位于物体右方的不同距离处 |
| 数量 | 1～20 条；未指定时默认 3 条 |
| 摆位 | 默认逐条递增种子，也可固定摆位；相同配置和种子可复现 |
| 数据 | 图像、状态、动作、时间戳、物体位置及成功标签；NPZ 与 JSON 清单 |

这里的“左侧、中央、右侧”指目标区在工作台中的位置。当前推移控制器始终沿世界坐标 +X 方向推移，尚不支持任意方向、路径规划和绕障。

当前不支持复杂环境、任意资产、多物体复合操作、倒水、插接、开门、装配、障碍物规划或自定义物理规格。识别到这些要求时会列出限制并阻止执行；未知物体或未说明操作时会要求修改描述。输入不会执行任意代码或命令。

Studio 当前使用本地规则解析，不能将任意自然语言要求直接转为可执行技能。已有平台的模型/资产生成入口仍独立保留，Studio 本版未调用这些服务；后端是否具备在线生成配置，以 `/api/v1/generation/capabilities` 的实际状态为准。

## 执行与数据规则

- 每次执行创建独立的 `studio_<id>` 项目和数据集，保留作业配置快照，不覆盖默认项目。
- 清单保存原始需求、最终编辑后的结构化方案、种子、配置以及专家版本；原始描述与最终方案可能因用户编辑而不同，以最终方案和配置快照为执行依据。
- 方块使用盒体碰撞，圆柱使用圆柱碰撞；物体保持自由刚体。推移通过夹指与物体的接触力完成，抓取通过夹爪接触和摩擦完成。
- 抓放成功要求接触、抬升、放到托盘并释放后稳定；推移成功要求接触后实际移动，进入目标区并在夹指撤离后稳定。
- 专家拥有物体位置等特权信息，不是已经训练好的模型。当前使用简化刚体、固定工具姿态，未进行实物参数标定。
- 相机前视为 512×384、腕部为默认分辨率；控制与样本记录为 20 Hz。实时预览每个控制 Tick 发布一次，原始相机采样时间保留在 NPZ 中。
- 回放显示动作执行前记录的观测和对应动作，不对记录值做插值。相机保留独立采样时间，显示的是该时刻可用的观测图像。
- 刷新恢复最近作业，不会重新提交。停止/中断作业可能保留部分文件，当前网页只对具备完整清单的数据集开放回放和下载。

## 启动

项目根目录：

```powershell
.\.venv\Scripts\python.exe -m uvicorn vlab.api:app --host 127.0.0.1 --port 8767 --no-access-log
```

前端目录：

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

如需开启原有平台的 Aholo 在线生成，在项目根目录的 `.env` 中配置 `AHOLO_API_KEY`，并运行 `python -m pip install -r requirements-aholo.txt` 安装可选 SDK。API 启动时自动加载 `.env`，已有进程环境变量优先；修改配置后重启后端。`.env` 已加入 Git 忽略规则，密钥仅由后端使用。该密钥用于 Lux3D 和 World，不替代需求规划器的 `AUX_MODEL_*` 配置。

## 新增接口

| 接口 | 用途 |
| --- | --- |
| `POST /api/v1/studio/plan` | 从 `prompt` 得到结构化方案、默认项和未支持要求 |
| `POST /api/v1/studio/preview` | 根据方案构建真实仿真初始场景并返回相机图像 |
| `POST /api/v1/studio/execute` | 保存独立项目、提交实际采集作业 |
| `GET /api/v1/studio/datasets/{dataset}/episodes/{index}/trace` | 读取回放时间轴、末端位置、夹爪开度、动作 |
| `GET /api/v1/studio/datasets/{dataset}/episodes/{index}/frames/{frame}/{camera}` | 读取指定记录的原始 JPEG，支持 front/wrist |

作业状态、日志、预览、停止及下载复用原有 `/api/v1/jobs` 和 `/api/v1/datasets` 接口。回放接口的 `{dataset}` 使用 `collection__studio_<id>`。
