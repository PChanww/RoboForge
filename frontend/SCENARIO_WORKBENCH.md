# 从需求到仿真与采集

入口：**http://127.0.0.1:5173/create**，也可从传送带 Demo 首页进入“描述场景，生成并仿真”。前后端启动方式见 [DEMO.md](DEMO.md)。

需要驾驶机器人时，打开 **`/drive`** [四轮移动实验室](MOBILE_DEMO.md)。移动演示采用独立物理会话；本页的抓取入箱仍按停靠方式运行。

需要“传送带抓取 → 移动搬运 → 指定箱位入箱”时，打开 **`/transport`** [移动抓取搬运](MOBILE_TRANSPORT.md)，在地图选择有限场区内目标，设置速度、物品参数和箱体外观。该入口可直接生成新物品与箱子外观，也可复用本页生成的物品和底盘。

## 网页操作

1. 分别描述环境、机器人外形、操作物品和工作状态。默认例子是仓库分拣区、停靠四轮机械臂、塑料小鸭、不停带随机姿态抓取入箱。
2. 为环境道具、机器人底盘和物品选择“生成新模型”或复用已有 Aholo 资产。环境还可选择不添加；固定机械臂无需生成底盘。
3. 点击“检查执行方案”。检查不提交在线生成，页面列出实际执行参数、能力边界、不可执行要求和本次需要新生成的资产数量。
4. 确认页面方案后点击“生成并开始仿真”。生成新模型会使用后端配置的 Aholo 额度；复用已有模型不会创建新模型生成任务。
5. 查看各角色的生成、下载、导入和组装进度。所有资产就绪且场景校验通过后，自动启动真实 MuJoCo 仿真和采集，支持前视／腕部相机切换。
6. 查看每条示范的真实成功或失败、帧数与时长，下载 JSON 清单和 NPZ 数据。需要修改要求时，点击“调整要求，开始新实验”。

生成需要等待，实时显示的是进度与后续仿真画面。描述新外形时应选择生成；选择复用会沿用原资产，不会根据文字修改旧模型。

## 本版执行范围

| 要求 | 实际能力 |
| --- | --- |
| 环境 | Aholo/Lux3D 生成一组货架、箱子等静态背景道具；缩放放置在工作区后方，包围盒参与碰撞 |
| 机器人 | 生成四轮底盘外观，与现有关节臂组装，停靠执行；也可用固定机械臂 |
| 物品 | 按外形描述生成单个小型刚体，默认高 6 cm、35 g，生成网格的凸包参与碰撞 |
| 工作 | 传送带抓取入箱；不停带或停带、随机或固定初始姿态、带速 1～4 cm/s、采集 1～20 条、指定起始种子 |

工作描述由明确规则解析，方案中的参数决定实际执行。识别采集次数、种子、带速及姿态等文字；网页参数控件修改时会清除文字中对应的旧设定。没有配置语言模型进行任意任务规划，未知文字不会增加新动作。导航、驾驶、装配、倒水、双臂及连续多物体来料等要求会被拦截。

每条 Episode 重置一个物体，逐条改变种子。环境是可碰撞的道具组合，并非完整房间生成；未使用 Aholo World 的 Gaussian PLY 作为可碰撞世界。物体质量、摩擦、环境包围盒等是演示估计值，未经实物标定。新造型和较高带速可能抓取失败，失败保存在数据中。

抓取、跟随、越过箱沿、箱内松爪和成功判定沿用 [DUCK_SORTING.md](DUCK_SORTING.md) 的真实接触流程，不向物体写入运行期位姿，不用焊接约束绑定物体。专家读取仿真状态，尚非视觉学习策略。

## 恢复和停止

网页保存草稿、提交 ID 和最近实验；后端将实验写入 `datasets/scenarios/`。同一提交 ID 恢复原实验，不重复创建收费任务。组装场景与采集分别使用独立项目和数据集，不覆盖默认项目。

网页打开时轮询推进后续步骤。关闭页面后保留后端任务与进度，重新打开可恢复并继续推进；本版不承诺关闭网页后无人值守完成整个流程。

“停止实验”阻止后续角色提交、场景组装和采集，并停止已关联的采集作业。已提交到 Aholo 的任务不会撤回，已生成资产保留。明确的远端、下载、导入失败可以恢复原任务；提交结果未知时阻止盲目重提，避免重复扣费。

## 接口和数据

| 操作 | 接口 |
| --- | --- |
| 能力与兼容资产 | `GET /api/v1/scenarios/capabilities` |
| 免费检查方案 | `POST /api/v1/scenarios/plan` |
| 提交实验 | `POST /api/v1/scenarios`，包含 `spec` 和稳定的 `client_request_id` |
| 读取与推进 | `GET /api/v1/scenarios/{id}`、`POST /api/v1/scenarios/{id}/poll` |
| 停止与恢复 | `POST /api/v1/scenarios/{id}/stop`、`POST /api/v1/scenarios/{id}/retry` |
| 相机、结果与下载 | 复用后端 jobs preview、datasets 清单和 episodes 接口 |

数据集在 `datasets/collections/scene_<id>/`。清单保留四项要求、解析参数、资产角色、生成来源、文件哈希、配置快照与实际结果。`scene_props` 记录静态道具来源和碰撞近似；固定机械臂不记录为四轮底盘。NPZ 包含双相机、机器人状态和动作、物体姿态、带速、阶段及时间戳。
